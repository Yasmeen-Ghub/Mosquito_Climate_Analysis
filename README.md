# Mosquito Climate Analysis

This repository contains the dataset and R Markdown code used in the manuscript examining the relationship between climatic factors and mosquito abundance in Osun State, Nigeria.

Contents:

- mosquito_abundance_data.csv : Mosquito abundance analysis dataset
- specie_specific_abundance_data.xlsx : Specie specific analysis dataset
- mosquito_Climate_Analysis.Rmd : executable R Markdown file containing all analyses

Software

- R
